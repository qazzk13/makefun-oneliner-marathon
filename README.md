A grown man still treats his dad's thermostat like a crime scene. He is 34, he turns it up one degree at a time, and he still stops to listen for footsteps coming down the hall, even though his dad now lives three hours away. The program writes that one line to the output file, checks it fits the 280 character limit first, and that is the entire entry.

## Run it

```sh
node main.ts
```
